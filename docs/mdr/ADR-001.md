# ADR-001: MDR-5D Architecture and Lossless Reconstruction Contract

Status: accepted (MDR-001)
Date: 2026-10-29
Branch: mdr/research

## Context

sqlite-mdr is a fork of SQLite 3.55.0 (public domain, fossil trunk e04c4f305).
MDR (Multidimensional archival compression) is researched inside the fork, but
the live storage engine is untouched until an offline archive path is proven.

## Decision

1. MDR is developed **offline first**: an MDR archive is a standalone file
   produced from (and restored to) a complete SQLite database file. It is NOT
   a `.sqlite` file and is never read by the SQLite engine. This lets
   folding experiments evolve freely without breaking standard readers.
2. A single reconstruction contract governs every MDR experiment:

   - Byte-for-byte restoration, verified by SHA-256.
   - Restored database passes `PRAGMA integrity_check`.
   - Compression numbers measured against zstd (multiple levels) and page
     deduplication (unique-page accounting); never claimed without a run.
   - Random data must show no compression gain (no false compression claims).
   - Upstream `src/` stays pristine on `mdr/research`; any engine change goes
     to `mdr/storage` only.

3. MDR components land under `mdr/<subsystem>/` as they gain code:
   core (now), fold / riemann / origami / generative / entropy / archive / vfs
   (later). No empty placeholder packages.

3. First transform (mdr/core/mdr.py): a "Riemann index permutation" — data is
   tiled into 32768-byte blocks (8 pages of 4096) and each block is transposed
   across five 8-wide axes (32768 = 8^5), i.e. a base-8 5-digit index reversal
   that mixes bytes across page boundaries within a tile. It is an involution,
   so fold and unfold are the same function. Honest framing: this is a pure
   permutation (no compression by construction) and one candidate tensor
   transpose, not a claim that folding beats zstd; the benchmark measures it.

## Consequences

- Benchmarks live in `benchmarks/mdr/`, docs in `docs/mdr/`.
- `mdr/research` may add directories freely; `master` tracks upstream.
- MDR-001 acceptance: roundtrip + integrity + measured baselines + random-data
  control, all executable via `benchmarks/mdr/bench.py`.

sqlite3 tester #1: Worker thread (@bitness@-bit WASM)

Variants: conventional UI thread: (32-bit, 64-bit), conventional worker: (32-bit, 64-bit), ESM in UI thread: (32-bit, 64-bit), ESM worker: (32-bit 64-bit)
Testers beware: the UI-thread tests may all run concurrently except that they may fail kvvfs tests because of concurrent access to that storage (it's so rare that it's never been seen in practice because those tests are so fast, but is hypothetically possible). The Worker-thread tests run OPFS tests, which are slow in some browsers and will fail if two instances of this page run them at the same time.
